# my-first-data-project

مشروع عملي بسيط لتطبيق أساسيات تحليل البيانات، يجمع بين **SQL** و**Python** في مسار متكامل: من استخراج البيانات إلى تنظيفها وتجهيزها للتحليل.

## 🎯 هدف المشروع

بناء سكريبت متكامل يوضح كيف يمكن الدمج بين قواعد البيانات (SQL) وبيئة بايثون (Pandas) لإنجاز مهام تحليل بيانات حقيقية، بدءًا من استخراج البيانات الخام وانتهاءً بمعالجتها وتنظيفها بشكل احترافي.

## 🧩 مكونات المشروع

| الملف | الوصف |
|---|---|
| `query.sql` | استعلامات SQL مركّزة لاستخراج البيانات وتصفيتها من قاعدة البيانات |
| `clean.py` | معالجة وتنظيف البيانات باستخدام مكتبة Pandas في بايثون |
| `README.md` | توثيق المشروع |

## ⚙️ خطوات التشغيل

1. نفّذي الاستعلامات الموجودة في `query.sql` على قاعدة البيانات لاستخراج البيانات المطلوبة.
2. صدّري نتيجة الاستعلام (CSV أو أي صيغة مناسبة).
3. شغّلي `clean.py` على الملف الناتج لتنظيف البيانات ومعالجتها:
   ```bash
   python clean.py
   ```
4. راجعي البيانات النظيفة الجاهزة للتحليل أو التصور البياني.

## 🛠️ الأدوات المستخدمة

- **SQL** — لاستخراج وتصفية البيانات
- **Python (Pandas)** — لتنظيف ومعالجة البيانات
